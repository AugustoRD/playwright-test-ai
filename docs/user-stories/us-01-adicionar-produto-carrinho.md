# US-01. Adicionar produto ao carrinho

## História

Como cliente da Renner, eu quero adicionar produtos à minha sacola de compras para reunir os itens que desejo comprar em um único pedido.

## Critérios de aceitação

1. O sistema deve permitir adicionar um produto à sacola após a seleção das características obrigatórias, como tamanho e cor, quando aplicável.
2. Após adicionar o produto, o sistema deve apresentar uma confirmação de inclusão e atualizar a quantidade de itens na sacola.
3. O sistema não deve permitir adicionar um produto indisponível em estoque.

## Regras e restrições

- Não é necessário estar autenticado (logado) no site para adicionar produtos à sacola.
- A funcionalidade deve estar disponível para usuários visitantes (não autenticados).
